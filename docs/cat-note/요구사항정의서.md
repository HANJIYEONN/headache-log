## 1. 서비스 개요

**한 줄 소개**: 어린이가 매일 다섯 문장씩 일기를 쓰면, 고양이 캐릭터 '콩이'가 맞춤법을 봐주고 칭찬해주는 글쓰기 습관 앱

**해결하려는 문제**: 글쓰기가 숙제처럼 느껴지는 아이들에게, "딱 다섯 문장"이라는 부담 없는 목표와 게임 같은 보상(발도장, 연속 기록, 친구 칭찬)으로 매일 쓰는 습관을 만들어준다.

**대상 사용자**: 글쓰기를 배우는 어린이 (초등 저학년 중심), 아이의 계정을 관리하는 부모

## 2. 기능 요구사항

중요도: **필수** = 이것 없으면 앱이 안 됨 / **권장** = 있어야 완성도가 남 / **나중에** = 1차 출시 후

### 2.1 인증 · 계정 (AUTH)

> 로그인은 **world holicat 사이트의 구글 로그인을 그대로 사용**해요.
> 고양이 수첩만의 아이디/비밀번호는 만들지 않아요. (결정 D-02)

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| AUTH-01 | 구글 로그인 | 사이트 공통 로그인. 로그인해야 고양이 수첩에 들어올 수 있음 (이미 구현됨) | 필수 |
| AUTH-02 | 역할 선택 | 고양이 수첩에 **처음 들어올 때 "아이 / 어른" 선택**. 이 선택에 따라 화면 모드가 달라짐 | 필수 |
| AUTH-03 | 수첩 아이디 만들기 | 친구가 나를 찾을 때 쓰는 아이디 (예: kongi123). 중복 불가, 첫 진입 시 설정 | 필수 |
| AUTH-04 | 회원정보 페이지 | 고양이 수첩 안에 별도 페이지 — 역할·수첩 아이디·프로필 확인 및 수정 | 필수 |
| AUTH-05 | 로그아웃 | 사이트 공통 로그아웃 사용 | 필수 |

### 2.7 화면 모드 (MODE)

> 같은 기능이지만 **누가 쓰느냐에 따라 화면 디자인이 달라져요.** (결정 D-03)

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| MODE-01 | 어린이 모드 | 큰 글씨, 손글씨 느낌, 콩이 캐릭터, 쉬운 말투 — 지금 프로토타입 디자인 | 필수 |
| MODE-02 | 어른 모드 | 차분하고 담백한 디자인 (어린이용 요소를 덜어낸 형태) | 필수 |
| MODE-03 | 모드 변경 | 회원정보 페이지에서 역할을 나중에 바꿀 수 있음 | 권장 |

### 2.2 문장 쓰기 (WRITE) — 핵심 기능 ⭐

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| WRITE-01 | 문장 작성 | 하루에 문장 5개를 하나씩 작성 (몇 번째 문장인지 진행바로 표시) | 필수 |
| WRITE-02 | 문장 수정 | 이미 쓴 문장을 다시 눌러 고칠 수 있음 | 필수 |
| WRITE-03 | 이어서 쓰기 | 쓰다 말고 나가도, 다음에 이어서 쓸 수 있음 (예: 3/5에서 재시작) | 필수 |
| WRITE-04 | 글감 제안 | "누구랑 놀았는지 써 볼까?" 같은 질문을 보여줌 | 권장 |
| WRITE-05 | 맞춤법 검사 | 5문장 완성 시 콩이가 선택한 언어(한/영/일)에 맞춰 맞춤법을 확인 ("조아요"→"좋아요"), 원본과 교정본 모두 저장 | 필수 | 
| WRITE-06 | 완성 처리 | "다 썼어요!" 누르면 완성 — 발도장 +1, 연속 기록 갱신, 축하 화면 | 필수 |
| WRITE-07 | 말로 쓰기 | 음성으로 문장 입력 (Web Speech API) | 나중에 |

### 2.3 홈 (HOME)

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| HOME-01 | 인사말 | "지우야, 안녕! 오늘도 다섯 문장 쓰러 왔구나 🐾" (별명 표시) | 필수 |
| HOME-02 | 오늘의 수첩 카드 | 오늘 진행도(n/5), 쓴 문장 목록(교정 표시 포함), "이어서 쓰기" 버튼 | 필수 |
| HOME-03 | 통계 카드 | 연속 기록 일수 🔥, 모은 발도장 개수 🐾 | 필수 |
| HOME-04 | 콩이의 한마디 | 콩이가 응원 멘트를 보여줌, 카드 좌우로 넘기기 | 권장 |

### 2.4 달력 (CAL)

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| CAL-01 | 발도장 달력 | 월 달력에 글 쓴 날마다 발도장 🐾, 오늘 날짜 강조 | 필수 |
| CAL-02 | 날짜별 글 보기 | 날짜를 누르면 그날 쓴 문장들 보기 + "전체 보기" | 필수 |
| CAL-03 | 목표 배너 | "🏆 10일 연속까지 2일 남았어요!" 진행 표시 | 권장 |

### 2.5 친구 (FRIEND)

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| FRIEND-01 | 친구 목록 | 친구 아바타 목록 표시 | 권장 |
| FRIEND-02 | 친구 찾기 | **수첩 아이디(AUTH-03)로 검색해서 추가** (결정 D-04). 이메일·실명으로는 검색 불가 | 권장 |
| FRIEND-03 | 친구 수첩 보기 | 친구의 오늘 수첩 (완성 🎉 / 쓰는 중 상태 포함) | 권장 |
| FRIEND-04 | 칭찬도장 | 친구 수첩에 💛 칭찬도장 주기 (개수 누적) | 권장 |
| FRIEND-05 | 댓글 | 친구 수첩에 💬 댓글 남기기 (비속어 필터 필요) | 나중에 |

### 2.6 내 정보 (PROFILE)

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| PROFILE-01 | 아바타 선택 | 동물 아바타(🐱🐶🦖🐰) 선택 또는 사진 업로드 | 필수(사진은 나중에) |

## 3. 비기능 요구사항 (기능은 아니지만 지켜야 하는 것)

| ID | 항목 | 내용 |
|---|---|---|
| NF-01 | 화면 | 모바일(폰 세로 화면) 기준 디자인, 손글씨 폰트 + 노랑/크림 파스텔 테마 |
| NF-02 | 보안 | 로그인은 구글에 맡기므로 비밀번호를 직접 저장하지 않음. 로그인 필요한 API는 전부 인증 검사 |
| NF-03 | 개인정보 | 어린이 대상 서비스 — 개인정보 최소 수집. 구글 계정 정보(이메일·실명)는 화면에 노출하지 않고 별명·수첩 아이디만 사용 |
| NF-04 | 안전 | 공개 피드 없음. 친구는 수첩 아이디를 정확히 아는 사람만 찾을 수 있음 (부분 검색·추천 없음) |
| NF-05 | 사용성 | 어린이가 읽기 쉬운 큰 글씨, 쉬운 말투 ("~해 볼까?"), 틀려도 혼내지 않는 문구 |
| NF-06 | 데이터 | 아이가 쓴 글은 절대 유실되면 안 됨 (문장 단위 즉시 저장) |

## 4. 이번에 안 만드는 것 (범위 제외)

- 앱스토어용 네이티브 앱 (웹으로 먼저)
- 부모용 별도 앱/대시보드
- 알림(푸시) 기능
- **부모님 설정 화면** — 1차에서는 만들지 않음 (결정 D-05)
- **고양이 수첩 전용 아이디/비밀번호 로그인** — 사이트 구글 로그인으로 대체 (결정 D-02)

| 번호 | 결정 내용 | 결정 이유 | 관련 기능 | 결정일 |
|---|---|---|---|---|

| D-04 | 친구는 **수첩 아이디로 검색**해서 추가 | 구글 로그인이라 아이디가 따로 없으므로, 검색 전용 아이디를 새로 만듦. 이메일이 노출되지 않고 별명처럼 중복되지도 않음 | AUTH-03, FRIEND-02 | 2026-07-28 |
| D-05 | **부모님 설정 화면은 1차에서 제외** | 로그인·비밀번호를 구글이 관리하게 되면서 부모님이 손댈 계정 설정이 사실상 없어짐. 글쓰기 기능에 먼저 집중 | AUTH-05 | 2026-07-28 |
