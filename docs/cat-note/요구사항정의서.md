## 1. 서비스 개요

**한 줄 소개**: 매일 다섯 문장씩 쓰면 틀린 곳을 짚어주고 칭찬해주는 글쓰기 습관 앱. **어린이는 모국어로, 어른은 배우는 외국어로** 써요.

**해결하려는 문제**: 글쓰기(또는 외국어 작문)가 부담스러운 사람에게, "딱 다섯 문장"이라는 작은 목표와 눈에 보이는 성취(발도장·연속 기록·정확도)로 매일 쓰는 습관을 만들어준다.

**대상 사용자**
- **어린이** (초등 저학년 중심) — 모국어 글쓰기 습관 만들기
- **어른 학습자** — 외국어(한국어 등)를 배우며 매일 작문 연습

## 2. 기능 요구사항

중요도: **필수** = 이것 없으면 앱이 안 됨 / **권장** = 있어야 완성도가 남 / **나중에** = 1차 출시 후

### 2.1 인증 · 계정 (AUTH)

> 로그인은 **world holicat 사이트의 구글 로그인을 그대로 사용**해요.
> 고양이 수첩만의 아이디/비밀번호는 만들지 않아요. (결정 D-02)

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| AUTH-01 | 구글 로그인 | 사이트 공통 로그인. 로그인해야 고양이 수첩에 들어올 수 있음 (이미 구현됨) | 필수 |
| AUTH-02 | 역할 선택 | 고양이 수첩에 **처음 들어올 때 "아이 / 어른" 선택**. 이 선택에 따라 화면 모드가 달라짐 | 필수 |
| AUTH-03 | 수첩 아이디 만들기 | 친구가 나를 찾을 때 쓰는 아이디. **영문+숫자 4~15자**, 중복 불가, 첫 진입 시 설정 (결정 D-10) | 필수 |
| AUTH-04 | 회원정보 페이지 | 고양이 수첩 안에 별도 페이지 — 역할·수첩 아이디·프로필 확인 및 수정 | 필수 |
| AUTH-05 | 로그아웃 | 사이트 공통 로그아웃 사용 | 필수 |

### 2.7 화면 모드 (MODE)

> **디자인만 다른 게 아니라 목적이 달라요.** (결정 D-03)
> 어린이는 **모국어로 글쓰기 습관**을, 어른은 **외국어 학습**을 목적으로 써요.

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| MODE-01 | 어린이 모드 | 큰 글씨, 손글씨 느낌, 콩이 캐릭터, 쉬운 말투. 발도장·칭찬도장 보상 | 필수 |
| MODE-02 | 어른(외국어 학습) 모드 | 차분한 톤, 문법 노트 중심. 정확도·스트릭·배운 표현으로 성취 표시 | 필수 |
| MODE-03 | 모드 변경 | **불가** — 첫 진입 때 고른 역할은 바꿀 수 없음 (결정 D-09) | — |

**두 모드 비교**

| 항목 | 어린이 모드 | 어른(학습) 모드 |
|---|---|---|
| 무엇을 쓰나 | 모국어로 오늘 있었던 일 | **배우는 외국어로** 오늘 있었던 일 |
| 교정 방식 | 맞춤법만 살짝, 혼내지 않는 말투 | **문법 노트**로 자세히 (어간·받침·발음까지) |
| 성취 표시 | 발도장 🐾, 연속 기록 🔥 | **정확도 %**, 스트릭, 배운 표현 개수 |
| 캐릭터 | 콩이가 말을 걸어줌 | 캐릭터 없이 담백하게 |
| 친구 | 아는 사람만 (수첩 아이디로 추가) | **전세계 학습 친구** (국적·배우는 언어 표시) |

### 2.8 외국어 학습 (LEARN) — 어른 모드 전용

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| LEARN-01 | 외국어로 문장 쓰기 | 배우는 언어로 다섯 문장 작성 ("오늘 있었던 일을 한국어로 써 보세요") | 필수 |
| LEARN-02 | 문법 노트 | 틀린 부분을 자세히 설명 — 어간·받침 규칙, 발음 표기, 예문 2개 | 필수 |
| LEARN-03 | 표현 추천 | 쓰는 중에 대안 표현을 칩으로 제안 (만났어요 / 만났습니다 / 만나서 놀았어요) | 권장 |
| LEARN-04 | 비슷한 실수 모아보기 | "비슷한 실수 3개 보기" — 같은 유형의 실수를 모아서 보여줌 | 나중에 |
| LEARN-05 | 단어장 저장 | 배운 표현·문법 노트를 단어장에 저장 | 권장 |
| LEARN-06 | 발음 듣기 | 내가 쓴 문장을 소리로 들려주기 (TTS) | 권장 |
| LEARN-07 | 번역 보기 | 문장을 모국어로 번역해서 확인 | 권장 |
| LEARN-08 | 정확도 | 오늘 정확도(예: 80%), 주간 정확도 추이(▲6% 지난주보다). **문장 기준 — 5문장 중 교정이 없는 문장 수** (결정 D-11) | 필수 |
| LEARN-09 | 오늘 배운 표현 | 오늘 새로 익힌 표현 목록과 개수(+2) | 권장 |
| LEARN-10 | 학습 친구 피드 | 전세계 학습자들의 오늘 기록 (국기·배우는 언어·완료 여부), 칭찬도장·댓글 | 권장 |
| LEARN-11 | 레벨 | 초급/중급 1 등 레벨 표시, "다음 레벨까지 표현 26개" 진행바 | 권장 |
| LEARN-12 | 피드백 언어 | 문법 설명을 어느 언어로 받을지 선택 (예: 영어로 설명) | 권장 |
| LEARN-13 | 매일 알림 | 쓸 시간을 알려주는 알림 켜기/끄기 | 나중에 |

> ❗ **문장 교정은 AI만 합니다.** 친구끼리는 칭찬도장·댓글로 응원만 하고, 서로의 문장을 고쳐줄 수 없어요. (결정 D-06)

### 2.2 문장 쓰기 (WRITE) — 핵심 기능 ⭐

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| WRITE-01 | 문장 작성 | 하루에 문장 5개를 하나씩 작성 (몇 번째 문장인지 진행바로 표시) | 필수 |
| WRITE-02 | 문장 수정 | 이미 쓴 문장을 다시 눌러 고칠 수 있음 | 필수 |
| WRITE-03 | 이어서 쓰기 | 쓰다 말고 나가도, 다음에 이어서 쓸 수 있음 (예: 3/5에서 재시작) | 필수 |
| WRITE-04 | 글감 제안 | "누구랑 놀았는지 써 볼까?" 같은 질문을 보여줌 | 권장 |
| WRITE-05 | 맞춤법 검사 | 5문장 완성 시 콩이가 선택한 언어(한/영/일)에 맞춰 맞춤법을 확인 ("조아요"→"좋아요"), 원본과 교정본 모두 저장 | 필수 | 
| WRITE-06 | 완성 처리 | "다 썼어요!" 누르면 완성 — 발도장 +1, 연속 기록 갱신, 축하 화면 | 필수 |
| WRITE-07 | 말로 쓰기 | 음성으로 문장 입력 (Web Speech API) | 나중에 |

## 3. 비기능 요구사항 (기능은 아니지만 지켜야 하는 것)

| ID | 항목 | 내용 |
|---|---|---|
| NF-01 | 화면 | 모바일(폰 세로) 기준 + **데스크톱 웹 레이아웃도 시안에 있음**(1d). 손글씨 폰트 + 노랑/크림 파스텔, 공책 메타포(줄노트) |
| NF-02 | 보안 | 로그인은 구글에 맡기므로 비밀번호를 직접 저장하지 않음. 로그인 필요한 API는 전부 인증 검사 |
| NF-03 | 개인정보 | 어린이 대상 서비스 — 개인정보 최소 수집. 구글 계정 정보(이메일·실명)는 화면에 노출하지 않고 별명·수첩 아이디만 사용 |
| NF-04 | 안전 | 공개 피드·전체 목록 없음. 친구는 **수첩 아이디를 정확히 아는 사람만** 추가 가능 (부분 검색·추천 없음). 역할(아이/어른)에 따른 제한은 두지 않음 — 결정 D-08의 위험 설명 참고 |
| NF-05 | 사용성 | 어린이가 읽기 쉬운 큰 글씨, 쉬운 말투 ("~해 볼까?"), 틀려도 혼내지 않는 문구 |
| NF-06 | 데이터 | 아이가 쓴 글은 절대 유실되면 안 됨 (문장 단위 즉시 저장) |
