## 섹션 1 — 홈 화면 3가지 방향 + 데스크톱 웹

홈 화면을 세 가지 스타일로 그려보고 고르는 단계였어요.

| | 이름 | 특징 |
|---|---|---|
| 1a | **공책 메타포** | 줄노트 위에 쓰는 수첩. 손글씨 느낌, "지우야, 안녕!" 인사 + 오늘의 수첩 카드 + 연속 기록/발도장 + 콩이의 한마디 |
| 1b | **카드형 깔끔** | 발도장 진행 링(3/5) 중심. "두 문장만 더!" + 글쓰기 시작 버튼. 탭이 홈/쓰기/**모아보기**/친구 |
| 1c | **스티커북** | 알록달록, 놀이 같은 느낌. 5칸 스티커 동그라미, 친구들 진행 상황이 홈에 바로 보임 |
| 1d | **데스크톱 웹** | 1b 스타일을 넓은 화면으로 확장. 상단 가로 메뉴(홈·글쓰기·모아보기·친구들) |

**→ 채택된 방향: 1a 공책 메타포** (섹션 2가 "공책 스타일로 나머지 화면"이라 이어짐)

📌 **데스크톱 화면도 이미 그려져 있음** — 모바일만 생각했는데 웹 레이아웃도 준비돼 있어요.
