## 🚨 1. 꼭 고쳐야 할 것 — 시안이 최신 결정과 어긋나요

### ① 짝꿍 고르기 화면 (3b) — **문구를 되돌려야 해요**

```
지금  : "한 번 고르면 바꿀 수 없어요"
바꿀 것: "나중에 내 정보에서 바꿀 수 있어요"
```

**왜:** 2026-08-02에 D-09(역할 변경 불가)를 보고 이 문구로 고쳤는데, **같은 날 나중에 D-17이 D-09를 뒤집었어요.**
화면이 하나로 통합되면서(D-16) 짝꿍은 **말투만** 정하게 됐고, 말투는 바꿔도 데이터·친구 관계에 아무 영향이 없어서 막을 이유가 사라졌거든요.

> ⚠️ **지금 시안은 앞뒤가 안 맞아요** — 프로토타입 "내 정보"에는 이미 **마스코트 바꾸기**가 있는데, 고르는 화면에선 "못 바꾼다"고 말하고 있어요.

### ② 어른 모드 안내문구 (4a)

```
지금  : "콩이가 한 번에 확인해 줘요"
바꿀 것: "먹물이가 한 번에 확인해 줘요"
```

**왜:** 5c에서 어른 톤 담당은 **먹물이**로 정해져 있어요. (이전부터 남아있던 항목)

### ③ 쓰기 화면 소제목 (2b)

```
지금  : "쓰면 바로 콩이가 봐줘요"
바꿀 것: "다 쓰면 콩이가 봐줘요"
```

**왜:** D-12 — 채점은 5문장을 **다 쓰고 완료 버튼을 눌렀을 때** 한 번에 해요. (이전부터 남아있던 항목)

## ➕ 2. 새로 반영할 것 — 오늘 정해진 결정

### ④ 친구 탭 — **친구는 최대 10명** (D-22)

화면에 **상한이 보이게** 해주세요.

- 친구 목록 상단에 개수 표시 — 예: **`내 친구 3 / 10`**
- 10명이 다 찼을 때:
  - "친구 찾기" 버튼을 **비활성**으로
  - 안내 문구: **"친구는 10명까지 사귈 수 있어요"**
- 친구 신청을 받았는데 내가 이미 10명인 경우에도 같은 안내가 필요해요

**왜:** 어린이 대상 서비스라 관계를 작게 유지하는 편이 안전하고, 친구 피드도 한눈에 들어와요.

### ⑤ 완료 후 화면 (6h) — **번역이 여기에 함께 나와요** (D-20)

- **번역 전용 화면·버튼은 만들지 마세요.** 채점 결과에 번역이 **같이** 담겨요.
- 6h의 교정 카드 안에 **번역 줄을 한 줄 추가**하는 형태예요:

```
┌─ 두 번째 문장 ────────────────┐
│  조아요  →  좋아요             │  ← 교정 (이미 있음)
│  💬 '좋다'에 '-아요'가 붙어요   │  ← 문법 노트 (이미 있음)
│  🌐 It's good.                │  ← 번역 (새로 추가)
└──────────────────────────────┘
```

**왜:** AI 채점이 하루 한 번뿐이라(D-12), 그 응답에 번역을 얹으면 추가 비용이 사실상 없어요. 별도 API를 만들 이유가 없어졌어요.

### ⑥ 아이디 만들기 화면 (2g) — **에러 문구는 3가지만** (D-19)

지금 필요한 안내는 이것뿐이에요:

| 상황 | 문구 |
|---|---|
| 이미 있는 아이디 | "이미 쓰고 있는 아이디예요" |
| 너무 짧거나 김 | "4~15자로 만들어 주세요" |
| 한글·특수문자 사용 | "영어와 숫자만 쓸 수 있어요" |

**금지어(욕설) 안내 문구는 넣지 마세요** — 금지어 검사는 2차로 미뤘어요.
