## 1. 서비스 개요

**한 줄 소개**: 어린이가 매일 다섯 문장씩 일기를 쓰면, 고양이 캐릭터 '콩이'가 맞춤법을 봐주고 칭찬해주는 글쓰기 습관 앱

**해결하려는 문제**: 글쓰기가 숙제처럼 느껴지는 아이들에게, "딱 다섯 문장"이라는 부담 없는 목표와 게임 같은 보상(발도장, 연속 기록, 친구 칭찬)으로 매일 쓰는 습관을 만들어준다.

**대상 사용자**: 글쓰기를 배우는 어린이 (초등 저학년 중심), 아이의 계정을 관리하는 부모

## 2. 기능 요구사항

중요도: **필수** = 이것 없으면 앱이 안 됨 / **권장** = 있어야 완성도가 남 / **나중에** = 1차 출시 후

### 2.1 인증 (AUTH)

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| AUTH-01 | 로그인 | 아이디 + 비밀번호로 로그인, 성공하면 홈으로 이동 | 필수 |
| AUTH-02 | 회원가입 | 계정 만들기 ⚠️ 방식 미정 (앱에서 직접 vs 부모님이 생성) | 필수 |
| AUTH-03 | 로그인 유지 | 앱을 다시 열어도 로그인 상태 유지 | 필수 |
| AUTH-04 | 로그아웃 | 내 정보 화면에서 로그아웃 | 필수 |
| AUTH-05 | 계정 정보 변경 | 아이디/비밀번호 변경 ⚠️ 부모님 설정 화면 미정 | 나중에 |

### 2.2 문장 쓰기 (WRITE) — 핵심 기능 ⭐

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| WRITE-01 | 문장 작성 | 하루에 문장 5개를 하나씩 작성 (몇 번째 문장인지 진행바로 표시) | 필수 |
| WRITE-02 | 문장 수정 | 이미 쓴 문장을 다시 눌러 고칠 수 있음 | 필수 |
| WRITE-03 | 이어서 쓰기 | 쓰다 말고 나가도, 다음에 이어서 쓸 수 있음 (예: 3/5에서 재시작) | 필수 |
| WRITE-04 | 글감 제안 | "누구랑 놀았는지 써 볼까?" 같은 질문을 보여줌 | 권장 |
| WRITE-05 | 맞춤법 검사 | 5문장 완성 시 콩이가 선택한 언어(한/영/일)에 맞춰 맞춤법을 확인 ("조아요"→"좋아요"), 원본과 교정본 모두 저장 | 필수 | 
| WRITE-06 | 완성 처리 | "다 썼어요!" 누르면 완성 — 발도장 +1, 연속 기록 갱신, 축하 화면 | 필수 |
| WRITE-07 | 말로 쓰기 | 음성으로 문장 입력 (Web Speech API) | 나중에 |

### 2.3 홈 (HOME)

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| HOME-01 | 인사말 | "지우야, 안녕! 오늘도 다섯 문장 쓰러 왔구나 🐾" (별명 표시) | 필수 |
| HOME-02 | 오늘의 수첩 카드 | 오늘 진행도(n/5), 쓴 문장 목록(교정 표시 포함), "이어서 쓰기" 버튼 | 필수 |
| HOME-03 | 통계 카드 | 연속 기록 일수 🔥, 모은 발도장 개수 🐾 | 필수 |
| HOME-04 | 콩이의 한마디 | 콩이가 응원 멘트를 보여줌, 카드 좌우로 넘기기 | 권장 |

### 2.4 달력 (CAL)

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| CAL-01 | 발도장 달력 | 월 달력에 글 쓴 날마다 발도장 🐾, 오늘 날짜 강조 | 필수 |
| CAL-02 | 날짜별 글 보기 | 날짜를 누르면 그날 쓴 문장들 보기 + "전체 보기" | 필수 |
| CAL-03 | 목표 배너 | "🏆 10일 연속까지 2일 남았어요!" 진행 표시 | 권장 |

### 2.5 친구 (FRIEND)

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| FRIEND-01 | 친구 목록 | 친구 아바타 목록 표시 | 권장 |
| FRIEND-02 | 친구 초대 | 친구 추가 ⚠️ 방식 미정 (아이디 검색 vs 초대 코드, 안전장치 필요) | 권장 |
| FRIEND-03 | 친구 수첩 보기 | 친구의 오늘 수첩 (완성 🎉 / 쓰는 중 상태 포함) | 권장 |
| FRIEND-04 | 칭찬도장 | 친구 수첩에 💛 칭찬도장 주기 (개수 누적) | 권장 |
| FRIEND-05 | 댓글 | 친구 수첩에 💬 댓글 남기기 (비속어 필터 필요) | 나중에 |

### 2.6 내 정보 (PROFILE)

| ID | 기능 | 설명 | 중요도 |
|---|---|---|---|
| PROFILE-01 | 아바타 선택 | 동물 아바타(🐱🐶🦖🐰) 선택 또는 사진 업로드 | 필수(사진은 나중에) |
| PROFILE-02 | 별명 설정 | 최대 8자, 인사말·친구 목록에 표시 | 필수 |
| PROFILE-03 | 소개 문장 | 나를 소개하는 한 문장 | 권장 |
| PROFILE-04 | 배우는 언어 선택 | 한국어 / 영어 / 일본어 ⚠️ 언어별로 맞춤법 검사가 달라짐 | 필수 |

## 3. 비기능 요구사항 (기능은 아니지만 지켜야 하는 것)

| ID | 항목 | 내용 |
|---|---|---|
| NF-01 | 화면 | 모바일(폰 세로 화면) 기준 디자인, 손글씨 폰트 + 노랑/크림 파스텔 테마 |
| NF-02 | 보안 | 비밀번호는 반드시 해시(bcrypt)로 저장, 로그인 필요한 API는 전부 인증 검사 |
| NF-03 | 개인정보 | 어린이 대상 서비스 — 개인정보 최소 수집, 14세 미만은 법정대리인 동의 원칙 |
| NF-04 | 안전 | 모르는 사람과 연결될 수 없는 구조 (공개 검색/공개 피드 없음) |
| NF-05 | 사용성 | 어린이가 읽기 쉬운 큰 글씨, 쉬운 말투 ("~해 볼까?"), 틀려도 혼내지 않는 문구 |
| NF-06 | 데이터 | 아이가 쓴 글은 절대 유실되면 안 됨 (문장 단위 즉시 저장) |
